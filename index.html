Import Registration Data

Import speaker and team registrations from Google Forms exports or Excel files.

Expected CSV/Excel Format

Your file should include the following columns (column names are case-insensitive):

  • email or Email Address - Required
  • name or Full Name - Optional
  • registration_type or Registration Type - "individual" or "team"
  • team_name or Team Name - For team registrations
  • partner_name or Partner Name - For team registrations
  • partner_email or Partner Email - For team registrations
Supported formats: CSV, XLSX, XLS
